# 内容取舍与模块布局

写作句式与禁用词见 [中文写作规则](writing-rules-zh.md)；页面、页数与 ATS 见 [ATS 与版式](ats-and-layout.md)。本文件只回答两件事：**写什么**、**放哪里**。

## 一、证据优先

先建立事实底稿，每个模块都从底稿取字，不从记忆或想象取字：

| 字段 | 说明 |
| --- | --- |
| 项目性质 / 时间 | 课题、实习、竞赛、课程、社团，起止月份 |
| 目标对象与痛点 | 谁的问题，原来怎么做的，卡在哪 |
| 本人职责 | 独立 / 主导 / 负责某模块 / 参与设计 / 配合，按真实档位 |
| 输入与方法 | 数据来源与规模、方法选择理由、工具与版本 |
| 产出 | 报告、看板、工具、模型、流程文档、被采纳的建议 |
| 验证方式 | 测试集、对照、专家复核、使用者反馈，有就写 |
| 完成阶段 | 原型 / 内部测试 / 试用 / 已交付 / 结题 |
| 对应 JD 能力 | 与 [JD 打分](jd-scoring.md) 的证据矩阵一致 |

三档可信度：**用户明确确认** > **材料记载** > **待核实**。只有前两档能进正式简历；待核实项单列清单，绝不进正文。

## 二、模块结构

默认顺序：**个人信息 → 教育背景 → 实习/项目经历 → 调研或实践 → 个人荣誉 → 技能优势**，空模块删除，通常 4–6 个。

- 研究生排在本科之前；同类经历按时间倒序。
- 项目可按相关性排序，日期保持真实（不要为了顺序改日期）。
- 有丰富全职经历者可把工作经历前移，并在修改说明里写原因。
- 跨专业（如本科数据科学 → 硕士应用统计）可在页首加**一句有证据的优势定位**，不要写成空泛自评。

各模块写法：

**个人信息**：姓名、年龄/籍贯（银行国企版保留，互联网版可省）、手机、邮箱，可选照片与求职方向一句话。必须有可选中文本，见 ATS 规则。

**教育背景**：学校（可标注 985/211 或双一流）、学院、专业、学位、起止月份、在读状态；按相关性选 GPA/排名与 3–5 门核心课程，注明口径（`89.96/100`、`排名 3/45`）。
- 应用统计/统计学的核心课程优先级：回归分析、多元统计、抽样方法、时间序列、因果推断、机器学习、数据可视化。只列与目标方向相关的。
- 学业奖学金并入教育模块，避免与"个人荣誉"重复。

**实习/项目经历**：每个项目 2–4 条，每条 1–2 行。项目之间分别证明不同能力（例如一个证方法链路，一个证协作与交付）。
- 项目标题行：`项目名 | 角色` + 右侧日期；下一行小字写 `性质（导师课题/实习/竞赛）｜ 我负责的一句话定位`。
- 实习写与目标岗位强相关的核心工作，剔除打杂内容；实习内容确实单薄时，把课程/竞赛项目补上，而不是把实习说得更满。

**调研或实践**：田野调研、问卷、社会实践压缩成 1–3 行，重点写**研究设计与结论**，不写过程流水。

**个人荣誉**：只留与学业/专业强相关、可核实的（奖学金、竞赛名次、优秀毕业论文）。一行一条，不占能力证明的位置。

**技能优势**：写成「工具/方法 + 能完成的任务 + 支撑经历」，分 2–3 组（分析工具、统计方法、AI 应用）。
- 普通 Office 不占篇幅；若 JD 明确要求高级 Excel（数据透视、Power Query、VBA）且有证据，写具体能力。
- 会使用 AI 工具（Coze、Dify、Claude Code、Codex）写"协作完成什么"，不要写成"熟悉 Agent 架构"。
- 不写"精通"除非能当场演示。

## 三、版面比例

- 实习 + 项目合计**至少三分之一**版面；项目是主证据时，项目自身不少于三分之一。
- 个人荣誉与技能合计通常不超过正文的 1/5。
- 事实不足时去挖真实经历（问出第二条方法细节），不要用重复句、拉大间距、放大字号填满。
- 一页装不下时按相关性加权删减，规则见 [ATS 与版式](ats-and-layout.md)。

## 四、事实边界（最容易出错的地方）

- 团队工作写明本人部分；别人做的即使理解透彻也不能写成本人业绩——可以写"复现"或"能解释"。
- 社团、竞赛、课题可以统一放在项目板块，但保留各自身份、组织与日期，不能拼接成虚构的商业实习。
- 专利区分申请 / 公开 / 授权，说明本人贡献与真实使用方法；专利不等于上线或已验证效果。
- 课程作业改写成业务问题表述时，必须保留"课程/竞赛"的属性，不能暗示为企业项目。
- AI 辅助是加分信息，但要能讲清分工（谁定需求、谁标数据、谁改提示词、谁做评估）。

## 五、加粗与关键词

- 与 JD 命中的能力短语、方法名、硬指标加粗，每条 1–3 处，避免整句加粗。
- 加粗位置配合 HR 的 8 秒扫视路径：模块标题下第一行、每条开头的能力短语。
- 专业名词用业内通行写法，中英文都能写，但同一份简历内保持一致。
