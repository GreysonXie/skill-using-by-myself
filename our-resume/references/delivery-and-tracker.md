# 双轨投递、跟进与面试衔接

简历不是一份，是**一套**：同一份事实底稿派生出的不同版本，各有用途。本文件管"投出去之后"的部分，避免投完就失联。

## 一、三种版本

| | 通用版（海投） | 精准版（定向） | 银行/国企版 |
| --- | --- | --- | --- |
| 用途 | 招聘网站批量投、宣讲会现场、朋友转发 | 心仪岗位、内推、明确 JD | 银行/国企/事业单位校招 |
| 篇幅 | 严格一页 | 一页；证据充足可两页 | 一页，可含照片与籍贯 |
| 模块顺序 | 教育 → 项目 → 调研/实践 → 荣誉 → 技能 | 可把最相关项目前移，或在页首加一句定位 | 教育 → 证书 → 实践/实习 → 荣誉 → 技能 |
| 措辞 | 可迁移的通用能力，少提特定行业 | 用 JD 原词重写主线与加粗 | 稳健、合规、稳定性，避免"AI 改造一切"式表述 |
| 技能栏 | 保留广度（Python/SQL/统计方法/AI 工具） | 按 JD 重排，前两项放命中的关键技能 | 突出数据治理、报表、风控方法、证书 |
| 自我评价 | 不写 | 不写 | 可写两句（如 JD 要求"综合素质"） |
| 何时不用 | 有明显更匹配的版本时 | 打分 < 15 时不必费力 | 互联网/外企岗不用 |

**版本间只改取舍与措辞，不改事实**。同一段经历在两个版本里数字不一致，是面试最快翻车的点。

## 二、投递前的 5 分钟清单

- [ ] 三道门槛已过（资格/语言/到岗），到岗天数与入职时间已确认
- [ ] 文件名规范：`姓名-岗位-学校.pdf`（例 `谢东骏-数据分析实习-西南财经大学.pdf`）
- [ ] 邮箱前缀是真实姓名拼音，能正常收信
- [ ] 手机号、邮箱在 PDF 里是可选中的文本
- [ ] `check_resume.py` 与 `check_pdf.py` 都无高风险告警
- [ ] 投递记录已建行（见下表）

## 三、投递记录表

用 `assets/examples/application-tracker.csv` 起步，字段固定为：

`日期, 公司, 岗位, 渠道(官网/内推/招聘网站), 版本(通用/精准/银行), JD链接, 打分, 状态, 下一步, 跟进日期, 备注`

状态只允许：`已投 / 已查看 / 笔试 / 一面 / 二面 / HR面 / Offer / 已拒 / 无回复 / 放弃`

规则：
- **每次投递必须留痕**，否则两周后就分不清投过谁。
- 一周回看一次：`无回复` 超过 10 个工作日 → 一次跟进；跟进后再无回复 → 标记放弃，把时间放到新岗位。
- 被拒也要记，并写一句最可能的原因（门槛不符 / 证据不足 / 笔试 / 面试表达）。连续 3 次同类原因，就是下一步要补的能力。

## 四、跟进话术（礼貌、简短、给信息不给压力）

**投递后 3–5 天（官网/招聘网站）**
> 您好，我是 X 月 X 日投递「XX 岗位」的谢东骏（西南财经大学 应用统计 硕士在读）。看到岗位仍在开放，想确认简历是否已收到。我做过两段与指标设计和数据核验相关的项目（可随时提供材料），如需补充信息我可以马上提供。谢谢！

**内推后跟进（给内推人，不发 HR）**
> 师兄/师姐好，感谢帮忙内推「XX 岗位」。我这边简历已按 JD 调整过，重点补了 XX 与 XX 两块。如果流程上有需要我补的材料或信息，随时说。

**面试后 24 小时内（发面试官或内推人）**
> 感谢今天的时间。关于您提到的 XX 问题，我补充一下我的思路：……。如果后续需要我提供项目材料或代码，我可以整理后发过去。

原则：一条消息只做一件事；不超过 5 行；不催结果；不复述简历。

## 五、内推推荐语（给对方转发用，先写成文字再发）

**短版（70–100 字，微信直接转）**
> 谢东骏，西南财经大学应用统计硕士（2028.06 毕业），本科数据科学与大数据技术，成绩 89.96/100。做过企业画像与专利匹配的分析项目（指标口径设计、TF-IDF+BGE 匹配、结果核验），也做过文本结构化工具的项目组长。Python/SQL/Tableau 可用，求职方向：数据分析/风控建模实习，可到岗时间 X 月，每周 X 天。

**长版（200–300 字，邮件或内推表）**
> 分四段：我是谁（学校/专业/毕业时间）→ 我能解决什么问题（2 个最相关项目，各一句方法 + 一句结果）→ 为什么是这个岗位（一段与 JD 的具体对应，不空夸）→ 可到岗时间与联系方式。
> 结尾一句：附件为简历 PDF，如需项目材料或代码仓库可以随时提供。

不要写：与岗位无关的兴趣、与岗位无关的奖项堆砌、夸张的自我评价、未核实的公司业务判断。

## 六、面试衔接：每段经历备三层追问

简历上每条被加粗的表述，都要能回答三层：

| 层 | 追问形态 | 你要准备的 |
| --- | --- | --- |
| 事实层 | 这条具体是什么？数据从哪来？规模多少？ | 时间、来源、规模、你的角色 |
| 方法层 | 为什么用这个方法？换一个会怎样？参数怎么定？基线是什么？ | 选择理由、对比方案、验证方式 |
| 结果层 | 结果怎么验证？谁在用？有什么局限？如果重做会改什么？ | 指标口径、使用方、局限与改进 |

答不上第三层时，**回到简历把措辞降一档**（`主导` → `参与设计`），而不是在面试里硬撑。

高频通用问题（统计/数据岗）：
- 介绍一个你从数据到结论的完整案例，中间推翻过什么判断？
- 你的指标口径是怎么定的？和业务方有分歧时怎么办？
- 样本有偏怎么办？显著但不重要怎么办？
- 为什么选这个模型？可解释性和效果怎么权衡？
- 如果给你一个全新业务，第一周你会做什么？

## 七、节奏与试错成本

- 宣讲会/校招直通（如银行 Pass 卡）：现场表现权重高于简历，提前准备 1 分钟自我介绍与 1 个项目故事。
- 大厂：投递记录会被系统留存，**没准备好不要拿最想去的岗练手**；练手用非目标公司或通用版海投。
- 首份实习优先看相关性与平台，避免无关经历"污染"简历主线。
- 面试被拒后主动要反馈（通过内推人或 HR 微信），把结论写进投递记录的备注里。
